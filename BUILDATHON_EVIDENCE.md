# Buildathon Evidence Note

## Purpose

This repository is intended to establish that a working controlled prototype was built and tested during the Future Caribbean Buildathon 2026.

It is deliberately **not** the complete commercial Roots 246 codebase.

## Buildathon scope

The prototype pressure-tested one canonical commerce flow using fresh produce in Barbados.

The build focused on:

- specialist-agent reasoning;
- evidence grounding;
- commercial viability;
- demand confidence;
- Winnie governance;
- autonomous GREEN execution;
- human-in-the-loop AMBER execution;
- RED / rejected stopping behaviour;
- action orchestration;
- movement planning;
- idempotency and uniqueness;
- reusable outcome intelligence.

## Five acceptance criteria

1. Multiple evidence sources can inform one transaction.
2. One evidence object can inform multiple specialist agents.
3. Different interfaces/systems can initiate or receive Roots actions.
4. Winnie controls what each evidence item is permitted to prove.
5. A completed transaction creates intelligence reusable by the network.

## Scope boundary

This is controlled prototype evidence.

It is not presented as proof of:
- live commercial adoption;
- production-scale logistics;
- repeatable willingness to pay;
- regional deployment;
- investment readiness.

Those are the next tests.
