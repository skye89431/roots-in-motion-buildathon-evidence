# Public Repository Safety

This evidence repository intentionally excludes:

- `.env` and all environment-specific secret files
- API keys and Shopify credentials
- local databases
- Shogo runtime files
- private datasets
- internal operating spreadsheets
- advisor correspondence
- customer/client data
- proprietary production implementation not required for Buildathon verification

If this repository is ever expanded, perform a credential and history scan before publishing additional files.
